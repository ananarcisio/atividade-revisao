# Atividades Práticas: Estruturas de Sistemas em Java

Este repositório contém a resolução de quatro atividades práticas focadas no desenvolvimento de lógica de negócios, POO (Programação Orientada a Objetos) e estruturação de dados utilizando a IDE **IntelliJ IDEA**.

🛠️ Descrição das Atividades
⛽ Questão 1 - Sistema de Abastecimento
Desenvolvimento de um sistema voltado para o gerenciamento de consumo e fluxo de insumos/combustíveis. O programa realiza o cálculo de autonomia, controle de frotas ou valores de abastecimento, aplicando regras de negócio para otimização de gastos e consumo.

🏫 Questão 2 - Sistema de Avaliação Acadêmica
Implementação de uma estrutura para gestão escolar e acadêmica. O sistema é responsável por automatizar o registro de estudantes, lançamento de notas, controle de frequência (faltas) e o cálculo automatizado de médias para definição de status de aprovação.

🚗 Questão 3 - Controle de Estacionamento
Aplicação desenvolvida para simular a operação de um pátio de estacionamento. Inclui a lógica para registro de entrada e saída de veículos, cálculo do tempo de permanência, controle de vagas disponíveis e a tarifação correspondente aos períodos utilizados.

💰 Questão 4 - Controle de Vendas
Desenvolvimento de uma ferramenta para monitoramento e análise de transações comerciais diárias. O programa automatiza o registro de faturamento, calcula médias de consumo, identifica os extremos de faturamento (maior e menor venda) e categoriza o volume de vendas por faixas de valores para fornecer um resumo estatístico do desempenho financeiro.

## 🚀 Tecnologias Utilizadas
* **Java** (Linguagem de desenvolvimento)
* **IntelliJ IDEA** (Ambiente de Desenvolvimento Integrado)
* **Git/GitHub** (Controle de versão e hospedagem do código)
